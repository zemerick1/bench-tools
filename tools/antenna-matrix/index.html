Aruba Antenna Matrix

External-antenna Aruba APs and the sticks, panels, and regrets you can bolt onto them. How many, omni or directional, which jacks. If the antennas are already hiding in the ceiling tile, you want a different page (or a ladder).

Covers connectorized models including AP-504, AP-514, AP-518, AP-534, AP-574, AP-584, AP-634, AP-654, AP-674, AP-734, AP-754, and AP-764, with AP-ANT, eANT, and outdoor N-type options from HPE QuickSpecs.

What this is: a pairing list from HPE QuickSpecs antenna tables, plus the obvious physics: the antenna has to cover the bands on those connectors. A tri-band omni still does 2.4 and 5, so a 504 can wear it. A 5/6 GHz-only outdoor panel cannot — those jacks still need 2.4 GHz, and they will not negotiate.

What this is not: a substitute for the QuickSpecs, an RF design, or proof that “tri-radio” means 6 GHz. AP-555 can run 2.4 + 5 + 5 with the antennas already on board. This tab has never visited your warehouse ceiling.
About the missing matrix (and our manners). HPE publishes the compatible-antenna list in QuickSpecs configuration tables, then also publishes a “data sheet” that forgot the antennas on the way to the PDF. We used the QuickSpecs. We did not raid their documentation empire with a duffel bag. If you need radiation plots and torque specs, Find SKU searches HPE for the part number. Manuals live on their Antenna Options family page; the model picker still enjoys a career in hide-and-seek.

FAQ

Is this official HPE guidance?

No. It is a helper built from public QuickSpecs antenna tables. Confirm on current HPE docs before you order or deploy.

Where are the internal-antenna APs?

They do not take these SKUs. AP-505, AP-555, AP-735, AP-765, and the other odd-numbered models have antennas built in.

Can I put a tri-band antenna on a 504?

Yes, if HPE lists it for that AP and the connectors match. AP-ANT-320 covers 2.4, 5, and 6 GHz — the 504 only uses 2.4 and 5. A 5/6 GHz-only outdoor antenna does not belong there, because those RP-SMA ports still need 2.4 GHz.

What about tri-radio and flex radios?

Radio count is not the same as 6 GHz. AP-555 is tri-radio 2.4 / 5 / 5, internal antenna, so it is not on this page. Flex radios can choose which bands are active; on connectorized 6E/7 APs the jacks are still split — a 2.4/5 GHz pair and a 6 GHz pair — so a 2×2 antenna is ordered twice, one for each pair.

Where are the install guides?

HPE Support keeps those under Antenna Options. Their model picker is the only public way to scope that page to a specific AP-ANT / eANT SKU — there is no stable per-antenna URL we can deep-link.
