FAQ

Where does this data come from?

Offline build from the HPE Aruba Networking AOS-CX CLI PDF (6200 series). The hierarchy is the PDF’s embedded outline (bookmarks). Previews are text pulled from the linked pages — not a live scrape of HPE’s site.

How do I refresh for a new AOS-CX release?

Drop the new PDF at tools/aos-cx-cli/source/cli_6200.pdf and run .venv/bin/python build_from_pdf.py from this folder (see README).

Is this the official CLI explorer?

No — unofficial helper for humans who hate scrolling a 2,700-page PDF. Always defer to current HPE documentation for production decisions.
