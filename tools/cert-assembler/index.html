Cert Assembler

Got a private key, a server certificate, and the CA’s bundle? Mash them into Apache/Nginx PEMs or a PFX / P12 — and slap a passphrase on (or peel one off) while you’re at it. All in this tab. Nothing gets uploaded.

Typical CA package (e.g. GoDaddy): they email or let you download a server cert plus a bundle / chain of intermediates. You already have the private key from when you made the CSR. This tool is the “now make files my server actually wants” step.
Stays local. Key material is parsed in your browser with a library we ship next to this page. Refresh the tab and it’s gone from memory.

    Where these formats usually go

    • Apache — SSLCertificateFile (cert or fullchain), SSLCertificateKeyFile (key), sometimes SSLCertificateChainFile (chain) on older configs.
    • Nginx — ssl_certificate is usually the fullchain (leaf + intermediates); ssl_certificate_key is the private key.
    • PFX / P12 — import into Windows cert store, IIS, some ADC/load-balancer UIs, or Java keystores (after conversion).

    FAQ

    Fewer “why won’t my server start” moments.

    Do you upload my private key?

    No. Parsing and packaging happen in your browser. There’s no assemble API on a server for this tool.

    What’s the difference between PFX and P12?

    Practically none for this use case — both are PKCS#12 containers holding key + cert(s). Different software just prefers different file extensions. We can emit either (or both).

    What is the “bundle” / chain file?

    Intermediate CA certificates that link your leaf cert up to a trusted root. Without them, some clients show chain errors even though your cert is valid. Paste whatever the CA labeled “bundle,” “chain,” or “intermediate.”

    Add vs remove a passphrase

    If your key is already encrypted, fill Current key passphrase so we can open it. Set Output passphrase to re-encrypt the PEM key and/or protect the PFX. Leave output blank to write an unencrypted PEM key (handy for many Linux web servers; protect the file with filesystem permissions instead).

    Key doesn’t match certificate?

    Usually means the key from CSR generation isn’t the same as the one you’re pasting, or you grabbed a cert for a different order. We refuse to build a PFX from a mismatched pair — that package would be useless (or worse, confusing).
