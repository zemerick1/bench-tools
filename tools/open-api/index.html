FAQ

Is this official HPE documentation?

No. Specs are pulled from the public developer hub and split for browsing. HPE’s published docs win when anything disagrees, and slices can be stale between refreshes.

Why not one giant Swagger / Scalar page?

Some of these documents are novels. Viewers choke. Each item in the sidebar is a self-contained spec for one tag (or a further split when that tag is still too large).

Can I send live API calls from this page?

Test Request is on so you can fill path, query, headers, and body and watch the snippet update. The response pane and Send control are hidden; this site does not fire live API calls. Copy the snippet and run it yourself. Header shape matches how the APIs authenticate: Mist is Authorization: Token <apiKey>; Central, UXI, ClearPass, and Axis are Authorization: Bearer <token>; SDC is x-api-key: <apiKey>; AOS-CX is a session cookie plus X-Csrf-Token after POST /login.
