FAQ

Is this official HPE documentation?

No. Specs are pulled from the public developer hub and split for browsing. HPE’s published docs win when anything disagrees, and slices can be stale between refreshes.

Why not one giant Swagger / Scalar page?

The Central OpenAPI document is 17+ MB. Viewers choke on it. Each item in the sidebar is a self-contained spec for one tag (or a further split when that tag is still too large).

Does Try Request work?

Scalar’s client is here. There is no proxy — requests go from your browser to the cluster URL in the spec. You need a valid token, and the API must allow the request (CORS often will not). Treat it as a convenience, not a guaranteed console.
