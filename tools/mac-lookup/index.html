MAC / OUI Lookup

Paste one MAC or a whole list—any common spelling. We’ll normalize it, flag likely randomized / locally administered addresses, and match the vendor from a local IEEE registry dump. Nothing leaves this tab.

Randomized MAC rule: look at the second hex character of the address (first octet’s low nibble). If it is 2, 6, A, or E, the address is locally administered unicast and likely randomized (Wi‑Fi privacy, many VMs, admin-set MACs). Example: da:a1:19:…
Formats we accept: full MACs (aa:bb:cc:dd:ee:ff, dashes, Cisco aabb.ccdd.eeff, bare, or aabbcc-ddeeff), or just an OUI (aabbcc, aa:bb:cc, aa-bb-cc — the usual 6 hex chars). Longer IEEE prefixes (7 = MA-M, 9 = MA-S) work too.

Addresses

One per line, or separated by commas / semicolons. Bulk paste from switch tables is fine.

Results

Collapsed by default — click a row for details. Header shows MAC + vendor. Inside each row, click any normalized form to copy it.

FAQ

How do you detect a randomized MAC?

For a unicast address, check the second hex character (the low nibble of the first octet). Values 2, 6, A, or E mean the IEEE U/L bit is 1 (locally administered) and the I/G bit is 0 (unicast). Phones’ Wi‑Fi privacy addresses use this pattern; so do many hypervisors and manually set MACs. We label that “likely randomized / locally administered,” not “definitely an iPhone.”

Why not only the vendor OUI?

Randomized and admin-set addresses often won’t match a meaningful consumer vendor—or will match a virtualization OUI. Bits first, registry second, keeps you from trusting a bad vendor string.

Can I look up just an OUI (6 characters)?

Yes. Paste aabbcc, aa:bb:cc, or aa-bb-cc. That’s the classic 24-bit OUI / MA-L prefix. We still apply the 2/6/A/E check on the first octet. You won’t get full-MAC-only notes (VRRP host patterns, etc.) because those need all 12 hex digits.

Is the OUI database online?

No. It’s a static oui-data.json built from IEEE’s public MA-L / MA-M / MA-S CSVs and shipped with the tool. Lookups never call home.

What can’t a MAC tell you?

Exact device model, user identity, location, or whether something is “on the network right now.” OUI org names can also be holding companies or ODMs, not the brand on the bezel.
