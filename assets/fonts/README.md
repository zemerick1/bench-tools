# Self-hosted fonts

IBM Plex Sans / Mono Latin WOFF2 files (SIL Open Font License).

Sourced from [Fontsource](https://fontsource.org/) builds of [IBM/plex](https://github.com/IBM/plex).
Hosted here so cert tools and the rest of the site do not contact `fonts.googleapis.com` / `fonts.gstatic.com`.

Weights:

- IBM Plex Sans: 400, 500, 600, 700
- IBM Plex Mono: 500, 600
